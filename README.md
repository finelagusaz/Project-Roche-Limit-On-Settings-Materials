# Project-Roche-Limit-On-Settings-Materials

## 設定の利用について

- フリーシェアワールド（FSW）宣言しているので設定の利用はご自由に。
  - 詳細: [フリーシェアワールドの提案 - 魔王14歳の幸福な電波](http://d.hatena.ne.jp/Erlkonig/20060911/1157930012)
  - 利用の際はFSW、二次創作なのか明記してもらえるとありがたいです。
- [イクサイスに関する設定の一部はくーげるしゅれいばーさんの方針に従うようお願いします。](http://altenotiz.sakura.ne.jp/)
- 知性プログラムの「大バベル」「オルタ」は、ウエ紙氏の[「人体視願／ヴィイ」](http://project.hacca.jp/)の設定をお借りしています。
- サイバースフィアは綾川くもさんが提唱する規格です。詳細は[サイバースフィア公式](http://leafstar.net/cybersphere/cybersphere.txt)を参照してください。
